# Measuring-Crime-Concentration-Near-MBTA-Stations-Boston
The project analyzes 2016–2025 Boston Police incidents to measure how crime concentrates near MBTA rapid-transit stations. Builds 1/3/5-minute walk isochrones, computes station-adjacent crime shares, trends by offense, time, line, and district, and maps hotspots. Reproducible geospatial code, clear visuals, and guidance for deployment.
